# Portrait Asset Provenance and Attribution

Status: evaluator-facing provenance record. The portrait files are not integrated into the Hunin
application or stored in this repository at this checkpoint.

## Asset package

The finalized external package contains 12 class portraits prepared as 800 x 1000 pixel WebP files,
one for each SRD class. The source package retains its manifest, checksums, prompt and review
provenance, and deterministic preparation record outside this public repository. Evaluators do not
need access to Marcela's local filesystem or personal account to run Hunin.

The images depict fictional characters. No real person, franchise, named setting, copyrighted
character, artist imitation, logo, or faction symbol was intentionally requested.
